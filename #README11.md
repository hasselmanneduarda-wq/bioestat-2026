# Tarefa 11 — Variáveis Aleatórias Aplicadas à Biologia

Este trabalho apresenta conceitos introdutórios de probabilidade aplicados a situações biológicas, utilizando Python para exemplificar diferentes tipos de variáveis aleatórias e os modelos de Bernoulli, Binomial e Poisson.

## Objetivo

Compreender e aplicar conceitos de variáveis aleatórias e distribuições de probabilidade em contextos biológicos, relacionando a formulação teórica dos modelos com cálculos, simulações e representações gráficas em Python.

## Conteúdo

O notebook aborda:

- definição de variável aleatória;
- diferença entre variáveis aleatórias discretas e contínuas;
- distribuição de Bernoulli;
- distribuição Binomial;
- distribuição de Poisson;
- simulações computacionais;
- interpretação biológica dos resultados;
- comparação entre os modelos probabilísticos.

## Aplicações biológicas

Os modelos probabilísticos foram apresentados por meio de exemplos relacionados à Biologia.

No modelo de **Bernoulli**, é analisado um evento com apenas dois resultados possíveis, utilizando a germinação de uma semente como exemplo.

A distribuição **Binomial** é utilizada para representar o número de sucessos em um conjunto fixo de observações, também em um contexto de germinação de sementes.

Para a distribuição de **Poisson**, é considerada a contagem do número de insetos capturados por uma armadilha durante uma noite, utilizando uma taxa média de ocorrência.

## Dados utilizados

Os exemplos e as simulações apresentados no notebook utilizam dados simulados para fins didáticos. Os parâmetros foram definidos para representar situações biologicamente plausíveis e demonstrar o funcionamento dos modelos probabilísticos.
